## Shared semantic edition path

Both products now call the shared C prompt, numeric validation and importance adjustment before freezing a new edition. Only the configured provider is used, outside database locks, with one 30-second deadline covering all inference calls. The complete eligible pool must contain at most 64 stories; larger pools retain deterministic selection. Foundation Models has a conservative input/output budget; no partial candidate pool or cloud fallback is substituted. Proposed merges require a second comparison of every member pair, capped at 64 pairs. Both apps use the shared C prompt and deterministic complete-clique partition: positive A–B and B–C links alone cannot merge A with C. Missing, duplicate, foreign or malformed pair identities discard the semantic plan; uncertain pairs remain separate. Whole JSON objects or arrays, optionally fenced, are accepted with explicit `members` or `pair` identities; positional guesses are never used. Pair dates are labeled `activity_date` because they derive from story activity, not necessarily publication.

Valid groups retain all source references and each constituent story revision. Consumption suppresses every constituent until material news changes it. Existing populated editions stay frozen; stale revisions or source membership changes during inference discard the plan. Migrations backfill old items as singleton groups. Invalid, overlapping, out-of-range and low-confidence groups cannot remove candidates; omitted candidates remain singletons. Shared fixture tests cross the Swift and Rust ABI adapters.

## Independent event ratings and fresh publisher evidence

Verification can split an incorrect primary group into different events. Those fragments now start with neutral importance (the existing base ranking) and “From your feeds” rather than inheriting a rejected combined score. Each fragment receives its own configured-provider request, containing only its exact member reports and a stable group ID. Rating validation uses shared C policy; neither model responses nor failures can change membership. The stage publishes all ratings together. Any malformed identity, missing answer, low confidence, context-budget failure or deadline expiry retains the original neutral verified groups.
